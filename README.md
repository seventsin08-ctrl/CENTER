# CENTER WebView APK

This wraps CENTER_V7.html in a native Android WebView.

## Build from your phone using GitHub
1. Upload the contents of this project to your CENTER GitHub repository.
2. Open **Actions**.
3. Choose **Build CENTER APK**.
4. Tap **Run workflow**.
5. When it finishes, open the run and download **CENTER-debug-apk**.
6. Extract the ZIP and install `app-debug.apk`.

The web app is bundled locally at `app/src/main/assets/www/CENTER_V7.html`.
